# CodeQuiz

A programming quiz app built with HTML, CSS and JavaScript.

**Live demo:** https://samiuallahganaie.github.io/quiz-app/

## Features
- Three topics with 8 questions each: Python Basics, HTML/CSS/JavaScript, and SQL & Git
- 20-second timer for every question
- Instant feedback showing the correct answer
- Questions and answer options are shuffled every time
- Score summary with a review of every answer
- Best score for each topic is saved in the browser

## Run it locally
No installation is needed. Download the repository and open `index.html` in a browser.

## What I practised
- DOM manipulation with JavaScript (building the interface without frameworks)
- Timers with `setInterval`
- Saving data with `localStorage`
- Responsive layout with CSS Grid and Flexbox
- Keyboard-friendly, accessible buttons and clear focus styles
